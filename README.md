# OUR NINE — Shared Group Photo Website

This is a simple shared photo wall for exactly 9 people:
- 1 Leader
- 8 Members

## Setup
1. Create a Supabase project.
2. Open SQL Editor and run `supabase.sql`.
3. Open `index.html`.
4. Replace:
   - YOUR_SUPABASE_URL
   - YOUR_SUPABASE_ANON_KEY
5. Replace the 9 names in `MEMBERS`.
6. Upload the folder to GitHub Pages, Netlify, Vercel, etc.
7. Send the website link to the group.

Important: This MVP lets anyone with the link upload under any of the 9 names. If you want each member to have a private login/unique upload permission, authentication should be added.
